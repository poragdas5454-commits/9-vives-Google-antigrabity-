# 9 Vives 👕

Premium T-Shirts & Modern Fashion — e-commerce web app.

## 🔗 Live Site

**[https://9vives.netlify.app](https://9vives.netlify.app)**

## ✨ Features

- 🛍️ Product listing & detail pages (Shop, Quick View)
- 🛒 Cart with drawer UI
- 🔐 User authentication (Firebase)
- 📦 Checkout & order confirmation
- ⚙️ Admin dashboard (products, orders, store settings)
- 🔥 Firebase Firestore backend with security rules

## 🛠️ Tech Stack

- **Frontend:** React 18 + Vite
- **Styling:** Custom CSS
- **Icons:** Lucide React
- **Backend:** Firebase (Auth + Firestore)

## 🚀 Run Locally

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```
